# 数据库连接问题诊断和修复指南

## 问题描述

1. 注册失败： "Database error saving new user"
2. 管理员页面无法创建新的 event 和 activity
3. 怀疑网站与数据库的连接出现问题

## 可能的原因

### 1. 触发器函数问题
- 触发器函数执行失败
- RLS 策略阻止触发器插入

### 2. 表结构问题
- events 表不存在或结构不正确
- activities 表不存在或结构不正确
- users 表结构不匹配

### 3. 权限问题
- RLS 策略过于严格
- 表权限不正确
- 角色权限不足

### 4. 数据库连接问题
- Supabase 环境变量未设置
- 客户端初始化失败
- 网络连接问题

## 解决方案

### 步骤 1: 执行诊断脚本

在 Supabase Dashboard 的 SQL Editor 中执行 `diagnose_database_connection.sql`：

这个脚本会检查：
- users 表结构
- events 表是否存在
- activities 表是否存在
- 触发器函数状态
- RLS 策略配置
- 表权限
- 数据库连接

### 步骤 2: 执行全面修复脚本

执行 `fix_all_tables_and_permissions.sql`：

这个脚本会：
1. 确保 users 表存在并正确配置
2. 修复触发器函数（最简单的版本）
3. 修复 users 表的 RLS 策略
4. 检查并修复 events 表的权限
5. 检查并修复 activities 表的权限
6. 授予所有必要的权限
7. 验证所有设置

### 步骤 3: 检查 Supabase 客户端配置

检查以下文件：
- `lib/supabase-client.ts` - 客户端 Supabase 客户端
- `lib/supabase-server.ts` - 服务端 Supabase 客户端
- `lib/supabase.ts` - 通用 Supabase 客户端

确保环境变量正确设置：
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### 步骤 4: 检查环境变量

在 Vercel 或本地环境中检查：
1. Supabase URL 是否正确
2. Supabase Anon Key 是否正确
3. 环境变量是否已加载

### 步骤 5: 测试数据库连接

1. 尝试注册新用户
2. 检查 Supabase 日志
3. 尝试创建 event
4. 尝试创建 activity
5. 检查错误消息

- 修复所有表的权限

### 3. 验证修复

执行以下查询验证：

```sql
-- 检查 users 表
SELECT COUNT(*) FROM public.users;

-- 检查 events 表
SELECT COUNT(*) FROM public.events;

-- 检查 activities 表
SELECT COUNT(*) FROM public.activities;

-- 检查触发器
SELECT * FROM pg_trigger WHERE tgname = 'on_auth_user_created_to_users';

-- 检查 RLS 策略
SELECT * FROM pg_policies WHERE tablename = 'users';
```

## 常见问题

### Q: 为什么注册仍然失败？

A: 可能的原因：
1. 触发器函数执行失败
2. RLS 策略阻止插入
3. 表结构不匹配
4. 权限不足

解决方案：
1. 执行 `fix_all_tables_and_permissions.sql`
2. 检查 Supabase 日志
3. 检查触发器函数

### Q: 为什么无法创建 event 和 activity？

A: 可能的原因：
1. events 表不存在
2. activities 表不存在
3. RLS 策略阻止插入
4. 权限不足

解决方案：
1. 检查表是否存在
2. 执行 `fix_all_tables_and_permissions.sql`
3. 检查 RLS 策略
4. 检查权限设置

### Q: 如何检查数据库连接？

A: 
1. 检查 Supabase 环境变量
2. 检查 Supabase 客户端初始化
3. 检查网络连接
4. 检查 Supabase Dashboard 状态

   - 验证表结构是否正确
   - 检查约束是否正确

3. **检查环境变量**：
   - 验证 Supabase URL
   - 验证 Supabase Anon Key
   - 检查环境变量是否已加载
