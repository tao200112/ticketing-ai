## 📊 项目概览

### 项目信息
- **项目名称**: PartyTix (ticketing-ai)
- **项目类型**: 智能票务管理系统
- **技术栈**: Next.js 15 + Supabase + Stripe + Vercel

```

│   ├── api/               # API 路由
```
